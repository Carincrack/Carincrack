## About

Full Stack Developer and Software Engineer based in Costa Rica. I build across the entire stack — architecting backend systems, designing APIs, and delivering frontend interfaces that are as thoughtful as the code behind them.

I work primarily with TypeScript, React, NestJS, and .NET. What drives my work is a deep respect for the craft: clean abstractions, intentional architecture, and code that reads like it was written to be maintained. I'm as interested in how a system is structured as I am in making it work.
