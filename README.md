## 👨‍💻 Sobre mí

Desarrollador **Full Stack** enfocado en construir sistemas que funcionen en producción y que se puedan mantener cuando los requisitos cambian. Trabajo en todo el stack — desde el diseño del esquema de base de datos hasta la interfaz que toca el usuario.

Me importa tanto **cómo está estructurado** un sistema como hacerlo funcionar: arquitectura limpia, abstracciones con intención y código que vale la pena leer.

- 🎓 **Ingeniería en Sistemas de Información** — Universidad Nacional de Costa Rica (UNA)
- 💼 Desarrollando el **módulo de Recursos Humanos** de un sistema de gestión hotelera (Práctica Profesional)
- 🔭 Construyendo servicios backend con **NestJS y .NET** usando CQRS y patrones event-driven
- 🌱 Profundizando en **Arquitectura Limpia y DDD** — en la práctica, no solo en la teoría
- 💬 Hablame de: TypeScript, arquitectura de software, sistemas POS, React
